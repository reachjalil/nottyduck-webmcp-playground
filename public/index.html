    HOW IT WORKS

    One world. Two ways to play.

    You and an agent operate the exact same game actions. The page registers typed WebMCP tools for movement, toys, customization, state, and local memory. Every change is immediately visible and saved only in localStorage.

    Human input always takes control. If WebMCP is unavailable, every feature remains usable with buttons, pointer, and keyboard.
